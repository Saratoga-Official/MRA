# 安卓打包（MaaFwApp）

MRA 的安卓版通过 **[MaaFwApp](https://github.com/Aliothmoon/MaaFwApp)** 出包。MaaFwApp 是
MaaFramework 的通用 Android GUI，它在**构建期**把一份 Project Interface V2 资源打进 APK，
运行时通过 [Shizuku](https://shizuku.rikka.app/) 或 root 起特权进程，截屏与点击走本机 native
controller，不经过 adb。

> 换资源 = 换配方 + 重新出包。资源随 APK 绑定，Android 端不支持热更新，也暂不支持 Mirror酱。

## 自动出包（CI）

仓库内 `.github/workflows/android.yml` 已完成全部接入：

1. 检出 MRA（含子模块，用于 OCR 模型）与 MaaFwApp。
2. `python configure.py` 生成 `assets/resource/model/ocr`，并把 `agent/`、`LICENSE`、
   `logo.png` 拷进 `assets/` 根（因为打包白名单相对 `assets/` 计算）。
3. `scripts/setup_maa_framework.py` 铺入 MaaFramework 的 Android `.so`。
4. `scripts/build_agent_bundle.py` 基于 `agent/requirements.txt` 组装内嵌 Python 运行时
   （`MaaFw` 由内核自带，会被自动跳过；`loguru` 会打进包）。
5. 通过 `pi-profile.yaml` + 环境变量出包，产物 `MRA-<tag>-android.apk`。

打 `v*` tag 时自动出包并附到对应 Release；也可在 Actions 里手动 `workflow_dispatch`。

## 本地出包

需要 JDK 17、Android SDK、Python 3。

```bash
git clone --recursive https://github.com/Saratoga-Official/MRA.git
git clone https://github.com/Aliothmoon/MaaFwApp.git

cd MRA
python configure.py                 # 生成 OCR 模型
cp -r agent assets/agent
cp LICENSE assets/LICENSE
magick "logo.ico[0]" logo.png && cp logo.png assets/logo.png   # 需 ImageMagick
cd ..

cd MaaFwApp
python scripts/setup_maa_framework.py --tag v5.14.1
python scripts/build_agent_bundle.py \
    --out "$PWD/../agent-dist" --abi arm64-v8a --abi x86_64 \
    --requirements "$PWD/../MRA/agent/requirements.txt"

# 指定配方
echo "pi.profile=$PWD/../MRA/pi-profile.yaml" >> local.properties

# 注入配方里的 ${...} 路径
export MRA_ASSETS_DIR="$PWD/../MRA/assets"
export MRA_AGENT_DIST="$PWD/../agent-dist"
export MRA_APP_ICON="$PWD/../MRA/logo.png"

./gradlew :app:assembleDebug        # 或 assembleRelease（需签名，见下）
```

产物在 `MaaFwApp/app/build/outputs/apk/`。

## Release 签名

默认 `assembleRelease` 打出的是**未签名**包，无法直接安装。配置签名后再出 release 包：
在 MaaFwApp 的 `local.properties` 或环境变量提供 `KEYSTORE_PATH`、`KEYSTORE_PASSWORD`、
`KEY_ALIAS`、`KEY_PASSWORD`。CI 默认产出 debug 签名包（可直接安装）。

## 版本说明

- MaaFramework Android `.so` 用 v5.14.1；agent 内核自带 maa 5.14 python 绑定。
  这与桌面端 `agent/requirements.txt` 里 `MaaFw==5.10.2` 的差异不影响安卓：
  打 bundle 时该 pin 会被内核自带版本覆盖。
- MRA 的 `interface.json` 图标为 `logo.ico`，Android 无法解码 ico，故 launcher 图标
  改用由 `logo.ico` 转出的 `logo.png`（见 CI 步骤）。

## 常见问题

| 现象 | 排查 |
|:---|:---|
| 一点开始就 native 加载失败 | `setup_maa_framework.py` 未跑或 ABI 不符 |
| 开始任务提示未带 agent 运行时 | agent bundle 未打进，检查 `MRA_AGENT_DIST` |
| 换了资源装上还是旧内容 | 清应用数据；版本号未变时可能沿用旧解包 |
| 运行日志 | `adb logcat -s MaaFw` |
